# Absürt Bahane Üreticisi

## Proje Hakkında

Bu depo, insanlığın en büyük sorunlarından biri olan **"geç kaldım ama bahanem yok"** krizine son vermek amacıyla geliştirilmiş, son derece ciddi, bilimsel ve akademik bir projedir.

Artık "trafik vardı" demek zorunda değilsiniz. Sistemimiz, derin öğrenme (yok aslında random), büyük dil modelleri (yine yok) ve yılların Türk halk bilgeliği kullanılarak üretilmiş absürt bahaneler sunar.

## Özellikler

- %100 Türkçe
- Gerçekten çalışan kod (denedim, çalışıyor)
- Kategori desteği: genel, is, okul
- Gizli özellikler (meraklılar için `--gizli` parametresi)
- Mahkemede kullanılamaz (önemli uyarı)

## Kullanım

```bash
python bahane_ureticisi.py
python bahane_ureticisi.py is
python bahane_ureticisi.py --gizli
```

Çünkü hayat zaten yeterince absürt. Bir de bahaneler de absürt olsun diye.
